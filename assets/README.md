# Assets

YAVSOS's own artwork and media, with editable sources and a note of where each came from:

- `icon/`: the mod icon (SVG source, 256 px and 1024 px PNG exports).
- `art/`: decorative art for the player guide and the store pages.
- `media/`: the guide's animations (GIF and MP4), cut from gameplay captures as `media/sources.json` describes.

Don't use another mod's artwork as YAVSOS's identity.
